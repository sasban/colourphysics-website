# colourphysics.com

The Colour Physics website: colour and appearance measurement, a service of Catuṣkoṭi (Pvt) Ltd. It's a single static page with no server code.

- `index.html` is the whole site. Edit the text here.
- `thanks.html` is shown after someone sends the request form.
- The request form posts to [FormSubmit](https://formsubmit.co) and arrives at contactus@catuskoti.com.

Published with GitHub Pages from the `main` branch. Every push goes live in about a minute.

The original client portal (Laravel app) lives in the private repo `catuskotisl/Colourphysics`.
